BAHAA'S WARDROBE — iPhone PWA package

To install on iPhone:
1. Upload the CONTENTS of this folder to an HTTPS static website/host.
2. Open its HTTPS URL in Safari on the iPhone.
3. Tap Share -> Add to Home Screen -> Add.

The app supports Casual, Smart/Old Money and Business/Formal categories; add/edit/delete looks; attach one main outfit photo, multiple individual garment photos and notes. Images and data are stored locally in this browser/device using IndexedDB. Do not clear Safari website data if you want to keep them.

This ZIP is the app package; it is NOT yet hosted at a public HTTPS URL, so it cannot be installed from the ZIP alone.
